# Package roles

## Frontend
- react: UI component framework.
- react-dom: renders React into the browser.
- react-router-dom: dashboard routing.
- axios: REST client.
- @dx-private/dxchart5-react: DXCharts React integration.
- @dx-private/dxchart5-modules: DXCharts modules.
- @dx-private/dxstudies: DXCharts studies.
- typescript: static typing.
- vite: frontend dev server/build tool.
- tailwindcss: styling.
- @tailwindcss/vite: Tailwind v4 Vite integration.
- @vitejs/plugin-react: React support for Vite.

## Backend
- fastapi: HTTP/WebSocket application framework.
- uvicorn: ASGI server.
- sqlalchemy: database ORM/data-access layer.
- alembic: database schema migrations.
- pydantic: typed data validation.
- pydantic-settings: environment/configuration management.
- loguru: logging.
- psycopg: PostgreSQL driver.
- numpy: numerical computing.
- pandas: historical market data/research.
- httpx: HTTP client and API tests.
- pytest: testing.
- pytest-asyncio: async testing.

## Optional execution
- MetaTrader5: Python bridge to the MT5 terminal; install only in the execution environment.
