# Automated Liquidity Trading Bot - Frontend

Modern React 19 + TypeScript dashboard interface for monitoring liquidity sweeps, market structures, volatility conditions, active trades, trade forensics, and performance metrics.

## Architecture

- `src/app/`: Application root, router, and context providers.
- `src/config/`: Environment configuration, API endpoints, and market symbols.
- `src/features/`: Modular domain features (dashboard, markets, trades, analysis, forensics, performance, settings).
- `src/layout/`: Topbar, Sidebar, MobileNavigation, and PageContainer layout shells.
- `src/shared/`: Reusable UI components, hooks, services, types, and formatters.
- `src/styles/`: Global variables, typography, and responsive styles.

## Getting Started

```bash
npm install
npm run dev
```
